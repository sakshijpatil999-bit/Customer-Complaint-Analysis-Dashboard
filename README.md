# Customer Complaint Analysis Dashboard

An interactive Power BI dashboard that analyzes customer complaints to identify trends, monitor resolution performance, and generate actionable business insights. This project demonstrates end-to-end data analytics using Power BI, Power Query, DAX, and Excel.

## Project Overview

The goal of this project is to help businesses understand customer complaint patterns, evaluate service quality, and improve operational efficiency. The dashboard provides an interactive view of complaints across products, regions, channels, and resolution status.

## Business Objectives

* Analyze customer complaint trends over time
* Measure resolution rate and SLA compliance
* Identify high-volume complaint categories
* Compare regional and channel-wise performance
* Support data-driven customer service decisions

## Tools & Technologies

* Power BI
* Power Query
* DAX
* Microsoft Excel
* Data Modeling

## Key KPIs

* Total Complaints
* Resolved Complaints
* Open Complaints
* Resolution Rate
* Average Resolution Time
* SLA Compliance
* Complaints by Category
* Regional Performance

## Dashboard Features

* Interactive KPI cards
* Monthly complaint trend analysis
* Category-wise complaint distribution
* Region and state performance analysis
* Channel-wise complaint comparison
* Dynamic slicers for filtering
* Business-focused visual reports

## Key Insights

* Identified the complaint categories contributing the highest volume.
* Measured regional differences in resolution performance and SLA compliance.
* Highlighted recurring customer issues to support service improvement.
* Delivered actionable insights through an interactive executive dashboard.
